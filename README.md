# CardLedger — concept demo

Mobile-first reputation platform for Pokémon card traders. **Concept demo only:**
the second trader and the PSA cert checks are simulated, and nothing is saved.

## Deploy (Cloudflare Pages, GitHub already connected)
1. Push this repo to GitHub.
2. Cloudflare Pages → Create project → connect this repo.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Deploy.

## Run locally (if you ever get a laptop)
`npm install` then `npm run dev`

"CardLedger" is a placeholder name — trademark/domain unchecked.
